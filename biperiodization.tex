\section{Problem definition}

The biperiodization process is needed to make a non-periodic 2D field periodic, in order to later apply discrete Fourier transforms. For this, an extension zone is defined on two sides of the original domain (called the ``physical zone''), which has to be filled with adequate values to make the whole field periodic.\\
$  $\\
The work of \cite{blazica_2015} reviews existing methods, and can be quickly summarized as follows:
\begin{itemize}
\item The extension methods of HIRLAM and ALADIN models are based on spline (ALADIN) or trigonometric (HIRLAM) functions, which are applied in both directions successively. They lead to wild overshoots in the extension zone and have a strong impact on the spectra.
\item The detrending approach requires a modification of the physical values.
\item The Boyd method is very good but requires data from outside the physical zone (e.g. from a large scale coupler).
\item The discrete cosine transform method produces accurate spectra but increases the total domain size by a factor 4.
\end{itemize}

\section{The EMF method}

The goal of this note is to design a method that:
\begin{itemize}
\item produces smooth extension values without overshoots,
\item does not require a modification of the physical values,
\item can be computed from the physical values only,
\item does not increase the total domain size too much.
\end{itemize}

This new method is called ``EMF'' for ``Extension, Mixing, Folding''.\\
$  $\\
We start with an initial random smooth field defined in the physical zone (P). The goal is to define values in the extension zone (E), and to make this process easier we also fill the opposite extension zone (E').

\begin{center}
\includegraphics[width=0.7\textwidth]{base_init.pdf}
\end{center}

\subsection{Extension}

As in the discrete cosine transform method, it is possible to extend the initial field using a symmetry operation with respect to the (P) boundary:

\begin{center}
\includegraphics[width=0.7\textwidth]{base_extended_sym.pdf}
\end{center}

The values in (E) and (E') have the same amplitude as in (P), which is good, but the field derivative is discontinuous at the (P) boundary, which is not ideal.\\
$  $\\
Another possible way to extend the field is to use an anti-symmetric operation with respect to the (P) boundary:

\begin{center}
\includegraphics[width=0.7\textwidth]{base_extended_antisym.pdf}
\end{center}

In this case, the first two derivatives of the field are continuous at the (P) boundary, which is good, but the field shows significant overshoots in (E) and (E') further away from this boundary, which is not desired.

\subsection{Mixing}
To attenuate the respective drawbacks of the two previous extension methods, a simple linear combination might be sufficient. The weights of this combination should be:
\begin{itemize}
\item higher on the first field (symmetric) away from the boundary, to avoid overshoots,
\item higher on the second field anti-symmetric) at the boundary, to keep continuous derivatives.
\end{itemize}

The \cite{boyd_2005} formula for a ramp going from 1 to 0 for an argument going from 0 to 1 can be expressed as:
\begin{align}
\mathcal{B}(x) = \frac{1}{2} \left(1+ \text{erf}\left(L\frac{1-2x}{\sqrt{4x(1-x)}}\right)\right)
\end{align}
For values of $L$ between 1 and 3, the ramp looks like:
\begin{center}
\includegraphics[width=0.4\textwidth]{boyd.pdf}
\end{center}

The mixing mask with $L_\text{mix} = 1$ is:

\begin{center}
\includegraphics[width=0.7\textwidth]{base_mixing.pdf}
\end{center}

This mask is applied to the anti-symmetric extension, and its complementary to the symmetric extension. The mixed field resulting from this linear combination is:

\begin{center}
\includegraphics[width=0.7\textwidth]{base_extended_mixed.pdf}
\end{center}

The continuity of the derivatives is preserved at the (P) boundary, while overshoots are kept at a managable amplitude.

\subsection{Folding}
In the final step, we apply the \cite{boyd_2005} folding method on this extended field, following two steps:
\begin{itemize}
\item applying the Boyd's mask on the extended field,
\item folding the domain to make the (P+E) zone biperiodic.
\end{itemize}

The folding mask with $L_\text{fold} = 2$ looks like:

\begin{center}
\includegraphics[width=0.7\textwidth]{base_boyd.pdf}
\end{center}

and the final result is:

\begin{center}
\includegraphics[width=0.7\textwidth]{base_folded.pdf}
\end{center}

We can check that the (P+E) zone is now biperiodic, with continuous derivatives at the (P) boundary and limited overshoots in (E). The field in (P+E) has been built from the values of (P) only, without modifying them.

\section{Implementation}

We denote $x$ the input values (from the (P) zone) and $y$ the intermediate and output values (in the (E) zone). The output value
\begin{align}
y = \sum_{i=1}^n y_i
\end{align}
is the sum of several components $y_1, ..., y_n$ because of the folding procedure, with $n$ depending on the point location in (E):
\begin{itemize}
\item right-top corner: $n=4$
\item right side: $n=2$
\item top side: $n=2$
\end{itemize}

For each component $y_i$, we can define two input points:
\begin{itemize}
\item $x^\text{bnd}_i$: closest points on the (P) zone boundary,
\item $x^\text{sym}_i$: symmetric point with respect to $x^\text{bnd}_i$.
\end{itemize}

The symmetric extension and anti-symmetric values are respectively given by:
\begin{align}
y^\text{sym}_i & = x^\text{sym}_i \\
y^\text{anti-sym}_i & = 2 x^\text{bnd}_i - x^\text{sym}_i
\end{align}

For each component, we denote $c^\text{mix}_i$ the local mixing mask and $c^\text{fold}_i$ the local folding mask. The final component value is given by:
\begin{align}
y_i = \left(c^\text{mix}_i y^\text{sym}_i + \left(1-c^\text{mix}_i\right) y^\text{anti-sym}_i \right) c^\text{fold}_i
\end{align}
which can be expressed as a linear combination of input values:
\begin{align}
y_i = \alpha^\text{bnd}_i x^\text{bnd}_i + \alpha^\text{sym}_i x^\text{sym}_i
\end{align}
with the linear coefficients:
\begin{align}
\alpha^\text{bnd}_i & = 2 c^\text{mix}_i c^\text{fold}_i \\
\alpha^\text{sym}_i & = \left(1 - 2 c^\text{mix}_i\right) c^\text{fold}_i
\end{align}
